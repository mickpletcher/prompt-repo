# Instruction Sets

Store persistent ChatGPT Project instruction sets in this directory. As the
collection grows, group related instruction sets into project or subject
subdirectories and use descriptive, lowercase kebab-case filenames.

Each instruction set should define its role, purpose, startup behavior, safety
or approval boundaries, workflow, and output format. Domain-specific sets should
also identify authoritative sources, assumptions, escalation criteria, and
information that must not be invented. Keep personal information and sensitive
project details to the minimum needed for the intended Project.
