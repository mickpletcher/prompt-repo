# Support

Use [GitHub Issues](https://github.com/mickpletcher/prompt-repo/issues) for:

- problems copying or adapting a resource
- unclear, incorrect, or outdated prompt instructions
- requests for new prompt or instruction-file categories
- improvements to repository organization and documentation

Include the affected filename, the tool you used, the expected result, and the
actual result. Remove account details, repository secrets, tokens, and private
project data before posting.

This repository provides reusable text resources, not guaranteed support for
the third-party tools or projects on which those resources are used.

For sensitive reports, follow [SECURITY.md](SECURITY.md) instead of opening a
public issue.
